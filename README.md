# LuxWatch

A full-stack e-commerce watch store built with HTML, CSS, JavaScript, and Flask.

## Features

- 🛍️ Watch product listing
- 🔎 Product search
- 🛒 Shopping cart
- 💳 Checkout simulation
- 📦 Stock management
- 🔐 Secure admin login
- 👨‍💼 Admin dashboard
- ➕ Add new watches
- 💾 Persistent product and cart data

## Technologies

- HTML
- CSS
- JavaScript
- Python
- Flask
- Git & GitHub
